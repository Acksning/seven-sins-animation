# INTP 七宗罪沙漏

为视频制作的可交互网页动画：3D 物理沙漏 + 七宗罪雷达图，用来呈现 **INTP 的傲慢与怠惰** 如何相互牵引。

> 傲慢抬高怠惰的阈值，怠惰滋养傲慢的幻觉。

## 这个网页是做什么的

这是我为了拍一支视频而做的**网页动画素材**。沙漏上室代表傲慢，下室代表怠惰；沙粒在 Rapier 物理引擎中真实堆叠、下落，点击「翻转」可整体倒转。背后的七边形雷达图标注七宗罪，突出傲慢 ↔ 怠惰这条主轴。

适合：

- 直接录屏用于 MBTI / 心理向视频
- 作为视觉参考进行二次创作
- 本地调参，导出你需要的沙漏形态与光感

## 本地预览

需要联网（Three.js、Rapier 走 CDN）。在项目目录启动任意静态服务器，例如：

```bash
python3 -m http.server 8765
```

浏览器打开 `http://localhost:8765`。

## 使用说明

### 页面操作

- **翻转**：顶部按钮，沙漏与雷达图一起旋转
- **右侧参数面板**：
  - **砂粒**：数量、半径
  - **瓶身**：高度、球泡、颈部、收口、腰线
  - 调好后点 **应用** 重建场景

### 修改沙粒与瓶身光影（代码）

主要改 `hourglass3d.js` 顶部常量：

| 用途 | 参数 |
|------|------|
| 沙粒颜色 | `GRAIN_COLOR`、`GRAIN_COLOR_PRIDE`、`GRAIN_COLOR_SLOTH` |
| 沙粒自发光 | `GRAIN_EMISSIVE`、`GRAIN_EMISSIVE_STRENGTH` |
| 瓶身边缘光 | `RIM_GLOW_COLOR`、`RIM_BASE_INTENSITY` |
| 体积晕光 | `HALO_INTENSITY`、`INNER_RIM_INTENSITY` |

雷达图样式见 `main.js`，布局与配色见 `style.css`。
